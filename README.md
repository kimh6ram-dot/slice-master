# 썰기의 달인 — 재료를 10조각으로, 최대한 일정하게

## 실행
- `index.html` 더블클릭(file://, 외부 의존은 Pretendard CDN 한 줄뿐, 빌드 없음). 폰: `node tools/serve.js` → `http://<PC-IP>:8080/`
- 자동 QA: `node tools/qa.js [--shots]` (규칙·채점 단위 검증 + 헤드리스 Chrome 흐름/키보드/터치/레이아웃, 스크린샷은 `screenshot/`)

## 규칙 (정본: `src/game/slicing.js`, 논리 단위 LENGTH=1000)
- 흐름: 시작 → 재료 선택(나루토 어묵·계란말이·연어·오이) → 플레이 → 결과 → 다시 썰기 / 재료 바꾸기. 시간제한 없음.
- 정확히 9번 절단 → 10조각. 마지막 조각 = 9번째 절단 ~ 오른쪽 끝(자동).
- 칼은 직전 절단 위치 ~ 오른쪽 상한 안에서만 이동 → 잘린 영역으로 못 돌아간다. 직전 절단에서 `MIN_T`(8) 미만이면 절단 불가 → 같은 위치 재절단·두께 0 조각 없음. 오른쪽 상한(`LENGTH − MIN_T×(남은 절단+1)`)이 어느 위치에서든 9번을 끝낼 수 있게 보장.
- 조작: PC ← → 이동 / SPACE 절단. 모바일 ◀ ▶ 누르는 동안 이동(떼거나 버튼 밖으로 나가면 정지), [썰기] 버튼 절단. 이동은 누를수록 가속(탭 = 5u 미세 이동).
- 4종 모두 같은 조작·같은 점수 기준(재료는 그림만 다름). 칼은 시작 시 재료 왼쪽 끝.

## 점수 (`scoring.js`)
`e = 두께 RMS 편차 / 이상 두께(100)`, `score = round(100 × (1 − min(1, e/0.5)))`. 완벽히 일정 = 100점. 참고: 편차 ±5→96, ±10→91, ±20→82, ±40→64.
결과 한 줄: 마지막 조각이 이상 두께의 135% 이상이면 "마지막 조각이 많이 두껍습니다 (+N%)", 아니면 가장 두꺼운/얇은 조각 편차.

## 조절 상수 (`src/game/config.js`)
`MIN_T` · `SPEED_MIN/MAX/RAMP_SEC/NUDGE`(이동 감각) · `CHOP_MS/SETTLE_MS`(연출) · `ZERO_AT`(점수 가혹도) · `GRADES`(등급 문구, **임시**).

- 저장소에 재료 PNG 가 없어 `ingredients.js` 가 캔버스로 직접 그린다. 사용자 PNG 가 오면 `ART[id]` 만 교체(조각은 이 스프라이트의 구간을 잘라 그린다).

## 3D 계란말이 (Three.js r186, `vendor/three.min.js` — 사과 깎기와 같은 IIFE 빌드, file:// 동작)
- 계란말이만 3D. 연어·오이·나루토 어묵은 기존 2D 그림 그대로(WebGL 이 없으면 계란말이도 2D 로 자동 대체).
- 파일: `tex3d.js`(절차적 색·노멀 텍스처) · `mesh3d.js`(조각 메시) · `view3d.js`(장면·카메라·칼·조각 애니메이션). 설정은 `config.js` 하단 `ROLL3D`.
- 절단 방식: 길이 축(x)에 수직인 평면으로만 자른다. 롤 = "단면 링(둥근 직사각형)이 x 에 따라 달라지는 곡면"으로 정의하고, 조각 `[a,b]` = 그 곡면의 일부 + 양쪽 평평한 뚜껑. 원래 양 끝(x<RE, x>L−RE)에서만 링이 오므라들어 둥글다. 절단 때마다 `slab(prev,x)` 조각과 `slab(x,L)` 몸통을 새로 만든다(복잡한 범용 절단·물리 없음).
- 무늬 연속: 옆면 uv.u = x/L(월드 x), uv.v = 링 인덱스 비율 → 어느 조각이든 같은 무늬가 같은 자리. 뚜껑 uv = 단면 좌표(고정) → 어디서 잘라도 같은 소용돌이.
- 두께 데이터: 조각 `geometry.userData.thickness` = b−a, 채점은 `slicing.js` 의 두께 배열(변경 없음).
- 잘린 조각: 왼쪽 아래 모서리를 축으로 짧게(220ms, 살짝 오버슈트) 기울어져 도마에 정착. 새로 자를 때마다 이미 잘린 조각들이 왼쪽으로 `SHIFT_G` 만큼 더 벌어진다. 기울기는 `min(TILT_MAX, asin(LIFT_MAX/두께), 왼쪽 이웃 + TILT_STEP)` — 이웃 조각이 서로 파고들지 않도록 제한.
- 비용: 보이는 메시 ≤ 24(조각 10 + 몸통/그림자 판 + 도마·칼), 삼각형 약 2100, 텍스처 몸통 1024² + 노멀 512² + 절단면 512²×2, 그림자맵 없음(도마 위 얇은 그림자 판), DPR ≤ 2, 오프스크린 WebGL 한 개를 모든 화면이 공유.
- QA: `node tools/qa3d.js`(메시 닫힘·평평한 절단면·끝만 둥긂·uv 연속·카메라 수평·겹침/도마 관통·예산·9회 절단·결과), `node tools/shot3d.js`(스크린샷).
- 에셋: `assets/aggroll.png` 는 **색 팔레트 측정**에만 썼다(윗면 #FBC431·앞면 #F0BA2F·절단면 #F8C63A). 이미지를 텍스처로 붙이지 않았다. 최종 그래픽이 아닌 **절차적(코드 생성) 임시 텍스처**이며, 더 가까워지려면 제작된 계란말이 모델/스캔 텍스처(.glb + 4K 알베도/노멀)가 필요하다.

## 가로형(16:9) 주방 장면 · 재료 4종 공통 3D 절단 (2026-11-04)
- **기준 좌표계 1920×1080**: `.app` 이 항상 1920×1080 이고 `main.js fitStage()` 가 창에 균일 배율 k 하나(transform scale)로 맞춘다. 캔버스는 `논리 좌표 × (DPR·k)` 로 그려서 배경·재료·칼·판정·UI 가 같은 좌표를 쓴다. 창이 16:9 가 아니면 단색 여백, 세로 화면은 비율 유지로 축소 + "가로로 돌려서 플레이하세요" 안내(`#rotate-hint`).
- 배경은 배율 `s = 1920/1672` 하나로 가로 전체(세로 연장·늘임 없음). 재료·칼 위치는 `config.js KITCHEN`(배경 px 단위).
- **재료 4종 모두 같은 3D 절단 구조**(`mesh3d.slab(a,b,id)`): 조각 = 단면 링을 길이 방향으로 압출한 옆면 + 양쪽 평평한 뚜껑(항상 닫힘). 원래 양 끝만 둥글고(`REL/RER`) 새 절단면은 평평. 외곽 링만 재료별(`config.js SHAPES`): 계란말이·연어 = 둥근 직육면체, 나루토 = 물결(골 16개) 원통(골이 길이 방향으로 모든 조각에 이어짐), 오이 = 원통(왼쪽 잘린 끝·오른쪽 둥근 끝).
- 몸통 텍스처: 연어(직육면체 펼침)·오이(원통 펼침)는 에셋 이미지를 둘레 좌표로 펼쳐 사용(u = 이미지 가로 그대로 → 조각을 늘이지 않음), 계란말이·나루토는 절차적. 단면 텍스처(`tex3d.js`)는 4종 모두 코드로 그림(에셋엔 정면 단면이 없음): 계란말이 노란 층+기공 / 연어 주황 살+크림 지방결 / 나루토 흰 속살+분홍 소용돌이 / 오이 초록 껍질+연한 속살+씨 부분.
- 재료는 보이는 외곽의 세로 중앙을 도마 위 같은 높이(`KITCHEN.YC`)에 맞춘다. 칼은 재료와 무관한 고정 크기·높이(`KNIFE_KS`, `KNIFE_TIP_Y`)로 칼끝은 도마 뒤쪽 위, 손잡이 끝은 도마 앞 가장자리 근처.

- 에셋 가공: `node tools/serve.js 8099` 후 `node tools/build_assets.js` → `src/game/assets_data.js`. knife_side.png 는 쓰지 않는다.

## 재료별 절단 횟수 · 반응형 · 드래그 · 효과음 · 도전장 · 새 배경 (2026-11-04)

- **배경 `kitchen_bg_v2`**: 도마 중심(`KITCHEN.CX`) 기준 확대(`ZOOM_MAX 1.30` ↔ 프레임 작을수록 `ZOOM_MIN 1.15`). 재료 중심 높이는 `YC_Y` 로 고정. 재료·칼·드래그 범위(`BOARD`)는 모두 배경 px × 같은 배율.

## 절단 연출 · 결과창 가로 배열 (2026-11-04)
- **절단 타임라인** `C.CUT`(ms): 0~PRESS 칼이 표면에 닿아 살짝 누름(재료 눌림 ≤ 1.4%) → PRESS~BOARD 칼날이 재료를 통과(조각 분리는 SEP 에 시작, '스윽') → BOARD 칼날이 도마에 닿음('탁') → CHOP_MS 에 복귀. 칼 이동 `dropAt`/`pressAt`(main.js), 소리 예약(audio.js)이 같은 값을 읽는다. 잘린 조각은 `sgOf(n)`(≥ SHIFT_MIN)만큼만 밀리고 멈춘다(틸트 ≤ 4°).
- **소리**: 스윽 버스/탁 버스 분리 — 연속으로 썰면 앞 스윽의 꼬리만 6ms 시정수로 끊고, 탁은 짧고 마른 나무 소리(≈55ms).
- **결과창**: 두 손(받침) 위에 낮은 수평 시점(`HANDS.AZ/EL`)으로 조각을 원래 순서대로 가로 한 줄. 줄 전체(길이+틈 합)를 `ROW_W` 에 맞추는 배율 하나만 써서 조각 수가 많아도 줄 전체가 같은 비율로 줄어든다. 두께는 실제 두께 그대로, 왼쪽 첫 조각의 단면이 살짝 보인다.

## 엔딩(토끼 셰프 덮개) · 절단 연출 재손질 (2026-11-04)
- **엔딩** `ending.js`: 한 컨테이너(ending_open 좌표계 1179×1334)에 3레이어 — ① ending_open(토끼 셰프·빈 접시, 고정) ② 재료(실제 썬 조각, `view3d.renderRowLayer` 로 한 번 렌더한 투명 레이어, 접시 위 낮은 수평 시점·접촉 그림자) ③ ending_cloche(닫힌 위치는 ending_close 와 맞춰 측정: `meta.ending.cloche`). 같은 배율·원점으로 그려서 PC·모바일에서도 덮개·재료가 접시의 같은 자리에 맞고, 덮개가 올라갈 컨테이너 위쪽 여백도 확보된다. 타임라인 `C.ENDING`: HOLD 500 → LIFT(챙) → RISE(후반 페이드아웃) → 재료 공개(점수·평가 표시, 팡파르 1회). 재료는 처음부터 덮개 아래 고정(가려짐으로 드러남 — QA 가 재료 유무와 닫힌 프레임이 같은지 검사).
- **소리**: 챙(`sfx.clink`)·팡파르(`sfx.fanfare`, 브라스 스탭+심벌 ≈1.5s) — 한 판에 한 번. 오른쪽 위 🔊/🔇 버튼으로 음소거(localStorage `cut_mute`, 절단음·엔딩 모두 적용).
- **절단 타임라인** `C.CUT`: PRESS(표면 닿음) → RESIST(저항) → BOARD(도마, '탁'·카운터 갱신) / SEP(막 잘린 조각 하나만 `NUDGE` 만큼 밀리고 멈춤). 칼 낙폭은 실제 15px 이상 보장(`MIN_DROP_PX`).
- 새 에셋 가공: `node tools/build_assets.js` (ending_open/ending_cloche → `meta.ending`). 예전 두 손 결과 화면(`ending.jfif`)은 에셋이 없어져 제거했다.

## 모바일 세로 UI 정리 (공통 틀 · 플레이 화면)
- 메인·재료 선택·결과: 같은 좌우 여백·콘텐츠 폭(80%)·메인 버튼 위치(`--btn-bottom`)를 공유. 위 콘텐츠를 버튼 쪽으로 붙여 쌓아(첫 요소 margin-top:auto + 공통 padding-bottom) 화면이 바뀌어도 버튼이 같은 높이. 넘치면 버튼이 콘텐츠를 따라가며 스크롤.
- 세로 플레이: 진행도(`썰기 0 / N`) → 주방 → 조작 바(◀ ▶ + 넓은 썰기) → 도움말 → 워터마크를 한 덩어리로, `fitStage`가 실제 높이를 재서 세로 가운데에 둔다. 가로로 돌리라는 안내는 첫 진입에만(localStorage `cut_rot_tip`) 도움말 줄로 표시.
